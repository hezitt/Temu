# 工厂报价表检查

来源文件：`领典数字油画最新报价.xlsx`。本页只记录与后续导入相关的结构和异常，不复制联系方式或地址等无关信息。

## 结构

- 1 个工作表，主要报价区域为 6 列。
- 颜色数包含 16、24、36、48、60。
- 价格分为画芯和框画两组，每组包含尺寸与未包邮价。
- 共有 43 个色数/尺寸行；拆分画芯/框画和 3 个分隔行后，解析 92 个候选：73 个有效报价、13 个无报价、6 个分隔行候选。
- 尺寸同时包含厘米和英寸文本。数据库保留原始 `source_size_label`，并另存标准化 `width_cm`、`height_cm`。

## 必须进入校验流程的内容

- `/` 代表没有报价，不能当作 0，也不能生成可定价 SKU。
- 色数组之间有分隔行，部分价格单元格为 0；这些不是商品报价。
- 里程碑说明把 `16色 / 20×20cm / 框画` 写成 9，但当前工作簿 `Sheet1!E4` 的 XML 是共享字符串索引 9，该索引内容为空；OpenPyXL 也读取为空字符串。导入以源文件为准，将它保存为 `NO_QUOTE`，不把共享字符串索引误当价格。若未来工厂文件中该单元格实际填入 9，系统会保留原值并产生 `SUSPICIOUSLY_LOW_COST` WARNING。
- 表头没有币种。当前 `settings.yaml` 暂按 CNY 配置；导入批次需要保存实际采用的币种。
- 所有价格均为“未包邮价”。物流成本以及标签、包装等成本没有在报价表中给出。
- 线稿处理费备注区分普通图和人物图，并表示处理后的线稿可复用。它更像一次性设计成本，不能未经分摊策略就作为每件成本相加。

## 后续导入建议

1. 为源文件生成 SHA-256，并创建 `import_batches` 记录。
2. 先转成规范化候选行：色数、原始尺寸、厘米宽高、是否带框、基础成本、币种、源工作表、源行号、原始值。
3. 把 `/`、空白、0、无法解析的尺寸和异常价输出到校验报告；不要静默丢弃。
4. 对有效候选行执行供应商 + 规格 + 生效日幂等写入。
5. 只有成本必需组件完整时才写 `total_variable_cost` 并标记 `VALID`；否则保持为空并进入人工复核。
