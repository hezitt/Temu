# 方果 ERP 适配边界（Milestone 2）

本文件只记录工厂资料中的业务事实，不执行也不自动化方果操作。

## 已核对的订单模板

- 工作表：`导入模板`
- 字段数：37
- 明确标注必填：`平台名称(必填)`、`店铺名称(必填)`
- 模板示例值包含平台 `Amazon` 和目标工厂 `领典美区数字油画pod工厂（工厂端）`
- 商品关联字段包括 `原商家编码`、`商家编码`、`SKUID`
- 定制素材字段包括主图、副图和 5 个定制图片字段

该文件是方果订单导入模板，不是 Temu 商品批量上传模板，不得用于生成
`temu_batch_listing.xlsx`。

## 素材命名

- 线稿：`{Factory Design Code}.jpg`
- 说明书：`{Factory Design Code}@说明书.jpg`
- 两个文件必须成对，说明书基名必须与线稿一致。
- 工厂资料明确要求图片名不能包含连字符 `-`，因此内部 Design ID 与 Factory Design
  Code 分开保存。

## 当前边界

已提供 `FangguoOrderAdapter` 协议和模板字段定义。尚未实现订单推送、店铺授权、
三方面单上传或工厂下单；这些动作留到后续里程碑并需要单独授权和验收。
